5. Is there anything special we need to know in order to run your code?

Use a recent TypeScript version supporting the starter's ES2023 target.
From the repository root, run:

    tsc --project tsconfig.json

Then serve this folder with a local web server, for example:

    python3 -m http.server 8000

Open http://localhost:8000/index.html. The other pages are activities.html and
descriptions.html. The starter HTML loads Bootstrap, Math.js, and Vega libraries
from CDNs, so normal use requires an internet connection.

Only ts/tweet.ts is the source for the Tweet class. js/tweet.js is generated by
TypeScript and remains ignored by git, as requested by the starter repository.
The submission ZIP also includes that compiled file for convenient previewing;
it can be regenerated with the command above.

All statistics, activity rankings, chart data, and textual conclusions are
computed from loadSavedRunkeeperTweets(); no dataset totals are hard-coded.
Dates and day-of-week groups use UTC to stay consistent across computers.
Distances are in miles (1 mile = 1.609344 kilometers). Duration-only activities
count toward activity totals but do not create distance observations. Entries
without a recognizable activity are excluded from activity-type counts.

Tweet classification and original-text detection use sharing-template rules.
The parser removes app-generated messages such as "Check it out!" and "TomTom
MySports Watch", automatic hashtags, and URLs before deciding if original text
remains. Search is case-insensitive and matches this original text, while each
result displays the full tweet with clickable HTTP/HTTPS links and its original
1-based position in the supplied dataset. Empty and whitespace-only queries
clear the result table.

The bonus button changes the named "distances" dataset in the same Vega view,
switching between individual distances and the mean for each activity/day pair.
Point tooltips show distance and the number of activities represented.
